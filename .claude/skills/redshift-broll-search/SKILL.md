# redshift-broll-search

## Запросы строятся на английском из смысла блока

**Не подстрочным переводом русского текста** — сток ищет по английским тегам, и
«квантовый чип» переведённый буквально даёт мусор. `src/lib/query.py` содержит
словарь предметных понятий канала; русские запросы сценариста используются как
источник понятий, а не переводятся.

На слот — 3–5 формулировок разной абстракции: конкретная → предметная →
метафорическая → фактурная. Если предметного кадра нет, метафора закрывает слот
лучше, чем пустота.

## Приоритет источников (§7.2)

| Тип запроса | Порядок |
|---|---|
| Космос, миссии, астрофизика | NASA → ESA → Internet Archive → генерация |
| Лаборатории, биотех, медицина | Pexels → Pixabay → Magnific |
| Города, люди, репортёрка | Pexels → Mixkit → Pixabay |
| Серверные, интерфейсы | Pexels → Magnific |
| Архив, история | Internet Archive (лицензия попозиционно) |
| Абстрактные data-виз | Magnific → Pexels |

Настраивается в `config/stock_sources.yaml`. **footage.net в free-tier пул не
включать** — это платный агрегатор.

## Бюджет скачиваний

≤50 материалов на ролик. Тратить их подряд нельзя: первые слоты выедят весь
бюджет, и хвост ролика останется пустым. Порядок работы:

1. собрать метаданные по всем запросам (бесплатно);
2. отбраковать дешёвыми признаками (шаг 1 §7.3 — отсеивает 50–60 %);
3. отранжировать: вертикаль → запас длительности → приоритет источника;
4. качать честную долю на слот (`оставшийся бюджет / оставшиеся слоты`).

## Лицензии (§7.2.7, §10.4)

Проверяются **до** скачивания. Материал без подтверждённой лицензии выбывает
сразу.

* Pexels / Pixabay — своя лицензия, нельзя порочащий контекст с узнаваемыми
  людьми, нельзя перепродавать как сток;
* Mixkit — бесплатно для коммерции, нельзя распространять как сток;
* **Internet Archive — лицензия у каждого объекта своя**, проверять
  попозиционно (R-10). Без явного PD/CC — мимо;
* NASA — в основном public domain, но логотипы NASA нельзя использовать как знак
  поддержки;
* Фрагменты фильмов, ТВ, интервью — **запрещены**.

## Дедуп (§7.2.5)

pHash/dHash, для видео — 3 кадра (10 %, 50 %, 90 %), порог Hamming ≤ 8/64.
Дедуп работает и внутри ролика, и против всей базы.

## Локальная база — всегда первая

Оценённый материал не покупается повторно. Материал из последних 5 роликов
отодвигается в хвост, но не выбрасывается: он всё ещё лучше пустого слота.
