# redshift-brandbook

Единственный источник правды по внешнему виду — `config/brandbook.json`.
Никаких «магических» чисел в коде: любое значение цвета, кегля, радиуса или
длительности анимации берётся оттуда.

## Палитра (§3.3, утверждена, конфликт K-1 закрыт)

| Токен | Значение | Где применяется |
|---|---|---|
| `bg_light` | `#F7F5F3` | основной светлый фон, плашки |
| `bg_pure` | `#FFFFFF` | полноэкранный текст, инверсия |
| `ink` | `#111214` | основной текст, тёмный фон |
| `accent` | `#C8453D` | акцент: одно слово, кнопка, подчёркивание |
| `accent_soft` | `#E4726A` | акцентное слово субтитра, градиент |
| `accent_deep` | `#8E2F2A` | тёмный акцент; обводкой субтитров больше не служит |
| `muted` | `#7A7D82` | подписи, второстепенный текст |
| `overlay_dim` | `rgba(10,10,12,0.78)` | затемнение, подложка-пилюля |

**Правила цвета:**
1. Акцент — не более 10–12 % площади кадра. Проверяется `accent_area_share()`.
2. Красным выделяется **одно слово**, не строка.
2a. Субтитры идут белым и **без обводки**: читаемость держит мягкая тень
   (`subtitles.shadow`). Цвет несёт смысл только на акцентном слове: на
   `gradient-fill` это кровавый градиент `accent → accent_soft`, на
   `clip-wipe` — сплошной `accent`. На `blend-difference` акцент
   остаётся `accent` и не блендится (иначе кровь уходит в циан).
   Одно слово на фразу, плотность добирает P4 (`top_up_emphasis`).
3. Максимум 3 цвета в кадре, не считая футажа.
4. Градиент только `accent → accent_soft`, ≤1 на ролик.
5. Инверсия (белое на красном) — только для полноэкранных цифр.

Фон под аватаром делай светлым и спокойным (`bg_light → bg_pure`). Заливка
акцентом выбирает весь лимит пункта 1 одним кадром.

## Safe zones (§3.2)

Рабочая зона: `x ∈ [90, 830]`, `y ∈ [150, 1520]`. Снизу 400 px — описание и
кнопки, справа 250 px — колонка лайк/коммент/шер, сверху 150 px — системный UI.
Проверяй через `SafeZones.contains()`; `SafeZones.violations()` называет, какая
именно граница нарушена.

## Типографика (§3.4)

| Роль | Гарнитура | Кегль |
|---|---|---|
| display (субтитры, заголовки, цифры) | Oswald Bold | субтитры 88 px в рабочей зоне, 200–420 полноэкранно, 140–260 за головой |
| subtitle (подписи, плашки) | Nunito ExtraBold | 44–52 px на карточках |
| mono (цифры, тикеры, код) | JetBrains Mono Bold | по месту |

Гарнитуру подключай только через `FontBook` — он проверяет кириллицу и лицензию
(см. скилл `redshift-fonts`).

## Анимационные константы

* **gradient-fill** (брендбук `subtitles.caption`, прод): bounce 1.04 и
  заливка акцента. Каталог тянет `backgroundPosition` по Siri-радуге —
  свойства нет, поэтому SVG-маска букв и сдвиг `x` у широкого rect.
  Радуга → `accent → accent_soft`, одно слово на фразу. Остальные белые.
* **clip-wipe** (космос: `category: space` или космические слова в теме):
  слово стоит, маска раскрывается слева направо (SVG-rect `scaleX`, не
  `clip-path`). Жёлтая вспышка каталога → `accent`.
* **camera-follow** — запасной жест по явному `caption` в плане: слова
  стоят, едет камера. Pop-in Nunito из проекта удалён.
* **blend-difference** — только явным `subtitles.caption` /
  `subtitle_style.caption`. Белые слова: статический
  `mix-blend-mode: difference` против футажа (не твин). Корень
  `#root` несёт `isolation: isolate`, иначе инверт считается с
  фоном страницы. Акцент — `mix-blend-mode: normal`. Прод по
  умолчанию не меняет.
* вход плашки: 200–280 мс с overshoot 6–8 %, уход 160–200 мс в ту же сторону
* Ken Burns: 1.0 → 1.08…1.15 за 2.5–5 сек, `ease_out_cubic`
* полноэкранный текст: вход 180–250 мс + приближение до 1.06
* подсветка: появление 200 мс, удержание 0.6–1.2 сек

## Чек перед коммитом рендера

- [ ] Все цвета и размеры пришли из `brandbook.json`
- [ ] Ни один элемент не вышел за safe zones
- [ ] Акцент ≤12 % кадра
- [ ] Текст читается на своём фоне (контраст проверен глазами, не предположен)
