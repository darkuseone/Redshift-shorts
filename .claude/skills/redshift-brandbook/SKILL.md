# redshift-brandbook

Единственный источник правды по внешнему виду — `config/brandbook.json`.
Никаких «магических» чисел в коде: любое значение цвета, кегля, радиуса или
длительности анимации берётся оттуда.

## Палитра канала: белый · чёрный · красный · бирюзовый (заказчик 22.09)

Четыре цвета канала и ничего больше. Роли — `brand_roles`, фирменные
элементы — `signature` в `config/brandbook.json`; разбор с примерами —
`docs/director/BRANDBOOK.md`.

| Цвет | Токены | Значение | Что им красится |
|---|---|---|---|
| **чёрный** | `space_deep #0A0A0B`, `ink #111214`, `panel #141517` | основа, космос, тишина | фон карточек, плашек, полноэкранного текста, финала |
| **белый** | `bg_pure #FFFFFF` | голос канала | весь текст |
| **красный** | `accent #D7263D`, `accent_soft #F2566B`, `accent_deep #8E1627` | эмоция, опасность, удар — «что почувствовать» | одно ключевое слово, знак вопроса хука, Subscribe, гало субтитров |
| **бирюзовый** | `cyan #36EFFF`, `cyan_soft #7AF0FF`, `cyan_deep #0BB8C9` | знание, данные — «что узнать» | цифры, счётчики, графики, источник, технические уголки, рамки плашек |

Служебные: `bg_light #F7F5F3`, `muted #7A7D82`, `text_soft #C9CCCF` —
поверхности настоящего интерфейса (окно браузера, статья), не цвета канала.
`overlay_dim rgba(10,10,12,0.78)` — затемнение.

Смысл блока → цвет акцента (`emphasis_family`): `myth`, `emotion` → красный;
`tech`, `number`, `source` → бирюза.

**Правила цвета:**
1. Акцент — не более 10–12 % площади кадра (QC-30).
2. Красным выделяется **одно слово**, не строка. Бирюза — цифра или знак данных.
3. В одном элементе один акцент; в кадре доминирует один, второй — мелкой деталью.
4. Бирюзовый текст — только на тёмном; на белом — `cyan_deep`.
5. Градиент только `accent → accent_soft`, ≤1 на ролик.
6. Цвет в коде — только токеном брендбука; новый литерал hex в рендере — брак.

Субтитры белые, читаемость держит **красное гало** (`subtitles.glow`):
ободок 2 px `accent` + зарево 8→90 px. Чёрной тени и обводки нет. Жесты
`gradient-fill` / `clip-wipe` / `blend-difference` — как раньше, цвет акцента
из токенов.

## Safe zones (§3.2)

Рабочая зона: `x ∈ [90, 830]`, `y ∈ [150, 1520]`. Снизу 400 px — описание и
кнопки, справа 250 px — колонка лайк/коммент/шер, сверху 150 px — системный UI.
Проверяй через `SafeZones.contains()`; `SafeZones.violations()` называет, какая
именно граница нарушена.

## Типографика (§3.4)

| Роль | Гарнитура | Кегль |
|---|---|---|
| display (заголовки, цифры) | Oswald Bold | 200–420 px полноэкранно, 140–260 за головой |
| subtitle (субтитры, подписи) | Montserrat Black, прописными | 84–104 px |
| mono (цифры, тикеры, код) | JetBrains Mono Bold | по месту |

Гарнитуру подключай только через `FontBook` — он проверяет кириллицу и лицензию
(см. скилл `redshift-fonts`).

## Анимационные константы

* **gradient-fill** (брендбук `subtitles.caption`, прод): bounce 1.04 и
  заливка акцента. Каталог тянет `backgroundPosition` по Siri-радуге —
  свойства нет, поэтому SVG-маска букв и сдвиг `x` у широкого rect.
  Радуга → `accent → accent_soft`, одно слово на фразу. Остальные белые.
* **clip-wipe** (космос: `category: space` или космические слова в теме):
  слово стоит, маска раскрывается слева направо (SVG-rect `scaleX`, не
  `clip-path`). Жёлтая вспышка каталога → `accent`.
* **camera-follow** — запасной жест по явному `caption` в плане: слова
  стоят, едет камера. Pop-in Nunito из проекта удалён.
* **blend-difference** — только явным `subtitles.caption` /
  `subtitle_style.caption`. Белые слова: статический
  `mix-blend-mode: difference` на клипе субтитра (соседе футажа, не твин).
  Корень `#root` несёт `isolation: isolate`. Акцент — второй клип без
  difference, иначе `#D7263D` уходит в циан. Прод по умолчанию не меняет.
* вход плашки: 200–280 мс с overshoot 6–8 %, уход 160–200 мс в ту же сторону
* Ken Burns: 1.0 → 1.08…1.15 за 2.5–5 сек, `ease_out_cubic`
* полноэкранный текст: вход 180–250 мс + приближение до 1.06
* подсветка: появление 200 мс, удержание 0.6–1.2 сек

## Чек перед коммитом рендера

- [ ] Все цвета и размеры пришли из `brandbook.json` (белый/чёрный/красный/бирюзовый)
- [ ] Ни один элемент не вышел за safe zones
- [ ] Акцент ≤12 % кадра
- [ ] Текст читается на своём фоне (контраст проверен глазами, не предположен)
