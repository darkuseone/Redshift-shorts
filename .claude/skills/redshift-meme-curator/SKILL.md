# redshift-meme-curator

## Жёсткие правила (§5.8, §14.3)

| Правило | Значение |
|---|---|
| Количество | 0–2 за ролик, типично 0–1 |
| Длительность | 0.5–1.5 сек |
| Категория `medicine` | **полный запрет** |
| Источник | **только локальная база** |
| Аудио | оригинальное не используется, только SFX |

## Content ID — главный риск

Мемы, содержащие узнаваемые фрагменты фильмов и ТВ **с оригинальным аудио**,
в базу **не попадают**. Это не перестраховка: такой мем ставит под удар
монетизацию всего канала.

Автоматически сгенерировать настоящую базу мемов нельзя — она курируется
человеком. `fill-libraries --kind memes` в mock-режиме кладёт карточки-заглушки,
помеченные `mock: true`, чтобы прогнать пайплайн; QC видит эту пометку.

## Триггер вставки

Только при **явном ироническом маркере** в тексте блока: ирония, абсурд,
«тупое действие», постирония, контраст ожидания и реальности.
Список маркеров — `IRONY_MARKERS` в `src/p5_replan/replanner.py`.

**При сомнении — не вставлять.** Неуместный мем стоит дороже отсутствующего.

## Отбор при вставке

Соответствие эмоции блока + не использовался в последних 10 роликах.
Эмоции: `ирония`, `абсурд`, `разочарование`, `удивление`, `сарказм`.

## Наполнение

До 15–20 новых мемов за прогон, чтобы не жечь лимиты и время. По достижении
100 библиотека замораживается, пополнение только вручную заказчиком.
