# redshift-script-validator

P0 отклоняет сценарий **с внятной ошибкой** до единого потраченного кредита.

```bash
python -m src.cli validate --script scripts/redshift_0042.json
```

## Коды ошибок (§8.2)

| Код | Условие | Что делать |
|---|---|---|
| `DURATION_OUT_OF_RANGE` | расчётный хронометраж вне 35–70 сек | ошибка называет, сколько секунд добавить или убрать |
| `MISSING_HOOK` / `MISSING_CTA` | нет блока с ролью | добавь блок |
| `HOOK_UNANSWERED` | хук не получает ответа | добавь ответ либо пометь блок `"answers_hook": true` |
| `QUOTE_TOO_LONG` | прямая цитата > 15 слов | пересказывай факт, а не текст источника |
| `NO_SOURCE` | нет источников при ai/space/tech/medicine | добавь `sources` |
| `MEME_IN_MEDICINE` | medicine + `allow_memes` | **не отказ**: мемы выключаются принудительно с warning |
| `FONT_MISSING_CYRILLIC` | гарнитура без кириллицы | см. `redshift-fonts` |
| `BUDGET_EXCEEDED` | смета выше лимита | снизь объём или подними `budget.max_cost_per_video_usd` |
| `SCHEMA_INVALID` | опечатка в имени поля | схема строгая: лишние поля запрещены намеренно |

## Как считается хронометраж

По слогам: `слоги / 5.4 сек` плюс микропаузы на знаках препинания. Это плотная
подача референсов (§2.2). Оценка расходится с фактом на единицы процентов;
точный хронометраж известен после P3.

## Структура блоков (§6, опорная сетка для 50 сек)

| Роль | Тайминг | Задача |
|---|---|---|
| `hook` | 0:00–0:03 | вопрос или факт-крючок |
| `setup` | 0:03–0:08 | что произошло, первый вход аватара |
| `evidence` | 0:08–0:22 | почему важно, откуда данные |
| `develop` | 0:22–0:38 | механика, цифры, последствия |
| `twist` | 0:38–0:46 | ответ на хук |
| `cta` | 0:46–0:50 | закрывающая мысль, кнопка подписки |

Хук длиной 8 секунд — частая ошибка: он съедает окно первого появления аватара
(≤0:06) и P1 сообщит конфликт `AVATAR_FIRST_APPEARANCE_LATE`.
