# SOP: плиты подложек через браузер Magnific

Порядок производства подложек (§7.6, Q3.6/Q3.9). Написан так, чтобы его мог
повторить другой агент или человек, ни разу не видевший этого проекта.

**Главное правило: ни одного вызова Magnific API.** Генерация идёт руками в
браузере, где Nano Banana 2 безлимитен по подписке. API тратит кредиты,
и это прямой запрет заказчика — «не трать токены магнифик». Инструменты
`mcp__Magnific__images_*` для этой задачи **не используются**.

---

## 1. Что именно делаем

Подложка — это вертикальная плита 1080×1920, за которой стоит ведущий. Их
пять по числу сцен `src/lib/backdrop.py`:

| Сцена | Файл | Состояние | О чём кадр |
|---|---|---|---|
| `horizon` | `horizon.jpg` | **есть** | чёрная дыра: тёмное поле, раскалённое кольцо аккреции |
| `grid` | `grid.jpg` | **есть** | техника: тёмная сетка с подсветкой |
| `space` | `space.jpg` | нужно сделать | космос: глубина, звёздная пыль, дальнее свечение |
| `depth` | `depth.jpg` | нужно сделать | недра: слои породы вниз, жар на глубине |
| `room` | `room.jpg` | нужно сделать | разговор: мягкая стена студии с боковым светом |

До Q3.6 сцена `space` была **алиасом** на `horizon.jpg` — ролик про космос шёл
на фоне чёрной дыры, и никто об этом не узнавал. Алиас снят: сцена без своего
файла честно рисуется градиентами, пока файл не положат.

Актуальный список недостающих — в коде, а не здесь:
`src.lib.backdrop.PLATES_MISSING`. Тест
`test_the_missing_plates_are_named_not_hidden` следит, чтобы этот список и
таблица сцен не разъехались.

## 2. Промпт

Один на все плиты, меняется только первая строка описания сцены. Строка
живёт в коде — `src.lib.backdrop.PLATE_PROMPT`, — чтобы новая плита делалась
той же формулой, что и прошлая:

```
vertical 9:16, dark cinematic plate, black / white / red #C8453D /
cyan #36EFFF only, no text, no logos, no people, subtle grain,
Netflix-investigation energy, negative space in the centre for a talking head
```

Перед ним добавляется описание сцены из таблицы выше. Пример для `space`:

```
deep space, star dust, distant glow, — vertical 9:16, dark cinematic plate,
black / white / red #C8453D / cyan #36EFFF only, no text, no logos, no people,
subtle grain, Netflix-investigation energy, negative space in the centre for a
talking head
```

Почему именно так:

* **`no people`** — за плитой стоит ведущий; второй человек в кадре читается
  как брак монтажа, а не как фон.
* **`negative space in the centre`** — центр занимает голова. Плита с
  композиционным центром сделает кадр спорящим сам с собой.
* **только четыре цвета** — палитра канала. Золото и жёлтый из референсов в
  каталог не переносятся: это прямое указание заказчика.
* **`no text, no logos`** — любая надпись на подложке спорит с субтитром и
  ломает `work_area` (лид-линт `tools/lint_composition.py`).

## 3. Порядок работы в браузере

1. Открыть Magnific в браузере под подпиской заказчика. **Не** через MCP,
   **не** через API-ключ.
2. Модель — Nano Banana 2 (безлимит по подписке; другие модели тратят
   кредиты).
3. Соотношение сторон — 9:16. Если модель отдаёт только квадрат, кадрировать
   до 1080×1920 **после** скачивания, а не просить модель «сделать высокий».
4. Вставить промпт из §2 с описанием нужной сцены.
5. Сгенерировать 4 варианта, выбрать один по критериям §4.
6. Скачать в максимальном разрешении.

---

## 4. Как выбирать вариант

Отбраковывать сразу, не жалея генерации — она бесплатна:

| Отбраковать, если | Почему |
|---|---|
| в кадре есть человек, лицо, силуэт | спорит с ведущим |
| есть буквы, цифры, логотипы, «водяные знаки» | §7.3 и лид-линт |
| в центре яркое пятно или объект | там будет голова |
| появился жёлтый, золотой, фиолетовый | палитра канала — четыре цвета |
| кадр светлее середины серого | подложка тёмная: на светлой пропадает белый субтитр |
| резкая деталь у нижней трети | там субтитр, `baseline_y` 1180 |

Проверить палитру числом, а не глазом:

```bash
python -c "
from src.lib.palette import accent_share
print(accent_share('assets/backdrops/space.jpg'))"
```

Доля акцента у подложки должна быть **низкой**: бюджет 0.12 на кадр (QC-30)
делится между подложкой, графикой и субтитром, и если плита выбирает его
целиком, акцентировать в кадре будет уже нечем.

## 5. Куда класть и что после этого сделать

```bash
# 1. Файл — строго с именем сцены
cp ~/Downloads/<скачанное>.jpg assets/backdrops/space.jpg

# 2. Прописать сцену в таблицу плит
#    src/lib/backdrop.py: PLATES["space"] = "space.jpg"
#    и убрать "space" из PLATES_MISSING

# 3. Тесты обязаны позеленеть — они следят и за файлом, и за списком
python -m pytest tests/test_shot_prepare.py -q -k Backdrop

# 4. Проверить, что плита доехала до кадра
python -c "
from src.lib.config import load_config
from src.p11_assemble.assemble import _backdrop_plate
print(_backdrop_plate(load_config(), 'space'))"
```

Тест `test_every_declared_plate_is_on_disk` упадёт, если сцену прописали, а
файл не положили; `test_no_scene_borrows_another_scenes_plate` — если две
сцены снова поделят один файл. Оба нужны именно потому, что алиас `space` →
`horizon.jpg` прожил в коде незамеченным несколько роликов.

## 6. Закрепить плиту за рубрикой или роликом

Автоподбор сцены идёт по тексту (`pick_scene`) и иногда промахивается: на
0047 слово «дыра» в ролике про сверхглубокую скважину поставило за спину
ведущего аккреционный диск. Спор решается файлом, а не правкой кода:

```jsonc
// config/backdrop_pins.json
{
  "by_video":    { "redshift_0047": "depth.jpg" },   // сильнее всего
  "by_category": { "space": "space.jpg" },
  "by_scene":    { "horizon": "horizon.jpg" }        // слабее всего
}
```

Порядок — от частного к общему: один проблемный ролик правится, не меняя
рубрику целиком.

---

## 7. Чего в этом SOP нет намеренно

* **Вызовов API.** Ни `mcp__Magnific__images_generate`, ни `images_upscale`,
  ни `simulate_cost`. Кредиты не тратятся ни на пробу.
* **Апскейла.** Плита показывается за головой, часто размыто и с наездом
  Ken Burns; апскейл здесь платит за резкость, которой зритель не увидит.
* **Генерации видео.** Подложка — неподвижный кадр; движение даёт `kenburns`
  и `parallax` уже в сборке.
