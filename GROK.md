# REDSHIFT — точка входа для Grok / GrokBot

Прочитай [`AGENTS.md`](AGENTS.md) — там весь протокол «тема → ролик». Порядок
действий тот же, что у любой другой нейросети; ничего не менять.

Особенности GrokBot (ВМ с браузером и CLI):

- **Magnific в браузере:** вход в аккаунт заказчика, сток — до 100 бесплатных
  скачиваний в день; генерация — только бесплатными моделями. Скачанное —
  в `assets/footage/director/<video_id>/` (≤15 МБ на файл) и в таймлайн.
- API xAI (ключ) не используется — ни генерация, ни vision (решение заказчика).
- В ВМ есть CLI Claude Code / Grok / Gemini: для голоса через ElevenLabs и
  аватара через HeyGen удобнее Claude Code с MCP; иначе голос — Actions фаза 1.
- Отбор футажа — своим зрением по кадрам (ffmpeg), vision-API не тратить.
- Заказчик может попросить: «сгенерируй через Magnific такое-то видео» —
  делай в браузере бесплатной моделью, остальное по протоколу.
- После сценария — стоп и согласование с заказчиком.
