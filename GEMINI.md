# REDSHIFT — точка входа для Gemini

Прочитай [`AGENTS.md`](AGENTS.md) — там весь протокол «тема → ролик». Порядок
действий тот же, что у любой другой нейросети; ничего не менять.

Особенности Gemini:

- Ресёрч и отбор футажа — своим поиском и своим зрением (скачал → кадры →
  посмотрел). Vision-API проекта для этого не нужен.
- Генерация картинок (если доступна) — только в пределах 20 % хронометража,
  файл кладётся в `assets/footage/director/<video_id>/`, в таймлайне
  `"ai_generated": true`.
- Нет ElevenLabs — голос делает Actions фаза 1 (`docs/director/VOICE.md`, путь Б).
- Файлы >40 КБ не читать целиком (правило в `CLAUDE.md`).
- После сценария — стоп и согласование с заказчиком.
