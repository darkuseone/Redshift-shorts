# REDSHIFT — протокол для любой нейросети

Этот файл — **канон**. Его читают все: Claude Code, Grok / GrokBot, Gemini,
Codex, Cursor. `CLAUDE.md`, `GEMINI.md`, `GROK.md` — только точки входа сюда.
Порядок действий одинаковый, кто бы ни открыл репозиторий.

**Что это.** Канал YouTube Shorts / Reels про науку и технологии: вертикальный
ролик 1080×1920, 25–70 с, голос заказчика (клон NIKITA2), иногда аватар
ведущего. Ты — **режиссёр и монтажёр**. GitHub Actions — станок: он только
скачивает, режет и рендерит то, что ты решил. Нейросети в Actions нет, поэтому
все творческие решения принимаются **в чате**.

## Протокол: тема → ролик

Заказчик даёт **тему** («что будет с котом в чёрной дыре»). Дальше строго по шагам.

### 1. Ресёрч
- Только реальные источники: научные статьи/пресс-релизы (NASA, ESA, arXiv,
  Nature…), свежие новости, посты в X и соцсетях. Ищи **последнее** по теме.
- Каждая цифра и факт — со ссылкой в `sources[]`. Не нашёл подтверждение —
  не пишешь. Выдуманная цифра — брак.

### 2. Сценарий — `docs/director/SCRIPT_STYLE.md`
- Простым языком, хук в первые 3 с (ротация типов), живая подача с сарказмом,
  финал — петля **или** «подпишись/лайк».
- Перед сценарием перечитай `config/owner_style.md` — там правки заказчика.
- Сразу продумай визуал: какие кадры реально найти, какие приёмы поставить.

### 3. СТОП — сценарий заказчику
Покажи сценарий текстом: блоки, хук, финал, источники, план картинки одной
строкой на блок. **Дальше не идёшь, пока заказчик не одобрит.** Его правки —
вносишь и **записываешь правило** в `config/owner_style.md` (было → стало →
правило). Это действует, пока заказчик явно не скажет «дальше без согласования».

### 4. Голос — `docs/director/VOICE.md`
NIKITA2, `eleven_v3`, темп 1.2–1.3, аудиотеги, драматические паузы. Дубль →
заказчику на прослушивание → правки, пока не понравится →
`tools/voice_import.py import` → `assets/voice/<video_id>/`.

### 5. Футаж — `docs/director/FOOTAGE.md`
- Реальный материал **≥80 %**, генерация **≤20 %** хронометража.
- Ищешь сам или субагентом по вебу, **скачиваешь и смотришь своим зрением**
  (кадры через ffmpeg). Vision-API xAI/Gemini на это не тратишь.
- Каждый футаж: `src` (прямой URL или файл в репо), `source`, `license`, `page_url`.

### 6. Шаблоны и VFX — `docs/director/TEMPLATES.md`
Выбираешь приёмы **явно**, по смыслу каждой фразы: полноэкранный текст,
счётчики и графики, плашки, hero-приёмы, переходы-VFX, движение кадра.
Картинка меняется каждые 1.5–2.5 с; на 30 с — не меньше 6 разных приёмов.

### 7. Таймлайн — `docs/director/TIMELINE.md`
Всё решённое кладёшь в секцию `director` сценария `scripts/<video_id>.json`:
какой футаж, с какого слова, каким переходом, какой приём поверх.

### 8. Проверка
```
python tools/director_check.py scripts/<video_id>.json     # 0 ошибок
python -m pytest -q --ignore=tests/test_music_library.py   # если менял код
```

### 9. Запуск станка
Коммит сценария + голоса, затем **отдельным коммитом** заявка
`config/ci_build_request.json`:
```json
{"script": "scripts/redshift_00XX.json", "video_id": "redshift_00XX",
 "from_step": "", "providers_mode": "live", "heygen_source": "prepared",
 "skip_generate": true, "skip_vision": true,
 "requested_by": "<claude|grok|gemini>", "note": "director, голос из чата"}
```
Push заявки на любую ветку запускает `build-video`. Готовый mp4 — artifact
Actions (`output/<id>/`), не git.

### 10. QC
Скачай артефакт, посмотри **кадры** (сетка каждые ~2 с + каждый стык) и
**звук** (хук / середина / финал). Ось по `config/qc_agent_rubric.json`,
выпуск только при ≥9/10 по всем осям. Правки — перерендер с кэша:
`from_step: "P11"` (визуал/таймлайн) — голос и аватар не трогаются.

## Железные правила

1. **Деньги — решение заказчика.** ElevenLabs и HeyGen тратят кредиты. Новая
   озвучка — только по одобренному сценарию; аватар — только когда заказчик
   просит. `--force-paid` в заявке не бывает.
2. **Ключи не печатать.** Секреты живут в GitHub Actions secrets.
3. **Аватар** — только HeyGen MCP → `assets/avatar_clips/<id>/`,
   `heygen.source=prepared`. Лук/движок — из `config/config.yaml`. Без аватара —
   `meta.avatar_mode: "none"`.
4. **Смена текста блоков = новый `video_id`** (иначе голос и липсинк не сойдутся).
5. **Одна версия монтажа.** Не A и B.
6. **mp4 не коммитить.** Футаж в репо — только если нет стабильного URL, ≤15 МБ,
   в `assets/footage/director/<video_id>/`.
7. **Файлы >40 КБ не читать целиком:** `templates/manifest.json`,
   `src/lib/render/hyperframes/templates.py`, `config/template_scenarios.json` —
   через индексы и `grep -n` (см. `CLAUDE.md`).
8. Индексы и каталог производные: `python tools/gen_indexes.py`,
   `python tools/gen_director_catalog.py` после правки шаблонов.

## Особенности агентов

| Агент | Что умеет особенного |
|---|---|
| Claude Code | субагенты для поиска футажа; ElevenLabs MCP; HeyGen MCP; Magnific MCP (кредиты) |
| GrokBot | браузер в ВМ: вход в Magnific и **бесплатные** модели/сток (100 скачиваний/день); свой Grok Imagine; CLI Claude Code / Grok / Gemini |
| Gemini | свой поиск и зрение; генерация Imagen, если доступна |

Если у агента нет инструмента из протокола (например, ElevenLabs MCP) —
голос делает Actions фаза 1 по ключу из secrets (`from_step: ""`, без
`assets/voice/<id>/`), остальное — так же.
