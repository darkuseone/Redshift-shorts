`config/owner_style.md`, философия кадра — `DESIGN_PHILOSOPHY.md`.

## Что сработало

| Решение | Как в 0052 | Почему |
|---|---|---|
| Живое видео вместо картинок | NASA SVS 14576 (Schnittman 2024, public domain): подлёт — диск растёт; нырок за горизонт | главный «вау» заказчика; две неподвижные картинки на 30 с читались как «чего-то не хватает» |
| Один фон на блок | кот нарисован поверх кадра того же блока (последний кадр подлёта, кадр нырка) | склейки внутри блока не рвут картинку |
| Один герой | один стикер-кот: живой — круглые глаза, за горизонтом — крестики | три разных кота = «рваная картинка» |
| Обложка = хук и финал | чистая обложка Canva (без надписей, дыра внизу) — фон хука; кот падает в неё; финал возвращается — петля | заказчик просил обложку в ролике; первый кадр = thumbnail |
| Обложка в thumbnail | `meta.cover` → P12 кладёт в `thumbnail.jpg` | исправленная вручную (Ё, без «_») |
| Переходы движением | whip-pan, light-sweep, zoom-through, blur-dip — только на смене блока | шейдерные вуали (chromatic, gravitational-lens, swirl-vortex, cinematic-zoom) заливают кадр красным |
| Звук на каждой склейке | P10 по окнам режиссёра: переход — вжух, удар — zoom-punch, тик — счётчик, `sfx` на акценты (пауза — sub_drop, макаронина — riser) | звук по слотам P5 шёл мимо склеек |
| Громкость Shorts | −10 LUFS, True Peak ≤ −1 dBTP, `audio.master: broadcast` | на −14 «еле слышно, только на полной громкости» |
| Подложка | эмбиент без струнных («Spacial Harvest», Kevin MacLeod, CC BY 4.0), 5–7 % от голоса, `meta.music_mood: space_harvest_drone` | скрипка под космос «так себе»; фон должен быть тихим |
| Голос | дубль заказчика **без ускорения**, P3 режет только паузы (36.6 → 31.0 с) | ×1.15 и ×1.05 — «быстро» |
| Длинное слово на экране | «СПАГЕТТИ- ФИКАЦИЯ» в две строки, на чёрном | кегль считается по самому длинному слову — вдвое крупнее |

## Рецепт по шагам (поверх `AGENTS.md`)

1. Сценарий → стоп → одобрение (правило 13 `CLAUDE.md`).
2. Голос: дубль ElevenLabs выбирает заказчик → `tools/voice_import.py import
   … --tempo 1.0` (без ускорения, если заказчик не попросит).
3. Футаж: сначала **живое видео** (NASA SVS, ESA, ESO — public domain / CC):
   ролик SVS режется ffmpeg в 9:16 на отрезки без титров, ≤15 МБ на папку.
   Картинки — только там, где видео нет.
4. Герой-стикер — **только где уместен по теме** (0052 — кот; в других темах
   может не быть). Если есть — один персонаж, `tools/sticker_anim.py` (fall / float /
   stretch; `--swap-sticker` для смены эмоции; `--scale/--pos` чтобы не лез под
   плашки). Фон стикера = кадр того же блока.
5. Обложка: Canva → проверить орфографию глазами → чистый вариант без надписей
   как фон хука, исправленная — `meta.cover`.
6. Таймлайн: переходы только движением и только на смене блока; внутри —
   прямые склейки; `sfx` на смысловые акценты. Оверлеи с цифрами — с `until`
   на слово следующей склейки, чтобы не висли над героем.
7. `tools/director_check.py` → **локальный mock-прогон** с Chrome HyperFrames
   (`node_modules/.bin`, голос берётся из `assets/voice/`, денег не тратит) →
   кадры каждые 0.5 с + каждый стык смотрятся глазами **до** CI.
8. Заявка в Actions → артефакт → кадры и звук ещё раз → заказчику.
