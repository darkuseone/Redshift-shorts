# Голос

**Голос:** NIKITA2, ElevenLabs `voice_id` `14NozJq5eoBmDc1FXFDq` (клон
заказчика, ru). Второй клон NIKITA (`7fU3YUxRrVGjNaZ5dzEH`) — только если
заказчик попросит.
**Модель:** `eleven_v3` — единственная, что понимает аудиотеги.
**Темп:** 1.2–1.3 от базового. ElevenLabs даёт максимум 1.2; остальное —
`atempo` в `tools/voice_import.py --tempo` (высота голоса не меняется).

## Подача

Живо, с иронией, местами со смешком. Не диктор новостей. Инструмент — аудиотеги
v3 в поле `tts_text` блока (в `text` их нет — оттуда субтитры):

| Тег | Когда |
|---|---|
| `[sarcastic]` | саркастическая реплика |
| `[laughs softly]`, `[chuckles]` | перед/после абсурдного факта |
| `[excited]` | удар, ответ на хук |
| `[whispers]` | «секрет», тишина перед ударом |
| `[deadpan]` | каменная интонация перед паузой |

Не больше одного тега на фразу — иначе голос «играет», а не говорит.

## Ударения

- Знак ударения прямо в `tts_text`: `сентября́`, `замо́к`.
- Постоянные ошибки — правилом в `config/pronunciation.json` (работает и для
  Actions-синтеза).
- После синтеза заказчик слушает и отмечает слова с ошибками → правка
  `tts_text` → новый дубль. Текст `text` при этом не меняется, `video_id` тоже.

## Паузы

- P3 режет все паузы >110 мс до 55–85 мс — речь плотная, «та-та-та».
- Исключения: пауза перед словом-ударом (`speech.punch_hold_ms`, 320 мс) и
  **драматическая пауза** режиссёра: `silence_after_ms` блока (до 3000) —
  тишина после блока держится, а если её не было — дорисовывается.

## Путь А — голос в чате (основной, Claude Code / агент с ElevenLabs MCP)

1. `python tools/voice_import.py prompt --script scripts/<id>.json` — текст
   для синтеза: `tts_text` блока или нормализованный `spoken_text` (числа
   словами, ударения из словаря).
2. ElevenLabs MCP `creative_generate_speech`: `voice_id` NIKITA2,
   `model_id: eleven_v3`, текст одним куском, 2–4 варианта. Заказчику —
   ссылка на flow: он слушает и выбирает дубль.
3. Скачать выбранный дубль (URL из `creative_get_flow_run_status`).
   Пословные тайминги — `creative_transcribe_audio` (scribe) → JSON.
   Без таймингов инструмент выровняет по энергии (хуже для субтитров).
4. ```
   python tools/voice_import.py import --script scripts/<id>.json \
       --audio take.mp3 --words take_stt.json --tempo 1.1
   ```
   `--tempo` — добор до 1.25–1.3 поверх скорости дубля. Результат:
   `assets/voice/<id>/voice_final.wav`, `speech_map.json`, `draft_plan.json`.
5. Коммит `assets/voice/<id>/`. В Actions P2 возьмёт этот голос и не будет
   синтезировать заново (кредиты не тратятся).

## Путь Б — голос в Actions (агент без ElevenLabs)

Без `assets/voice/<id>/` фаза 1 синтезирует по ключу из secrets:
`elevenlabs.model: eleven_v3`, `elevenlabs.pace: 1.2`, голос из `voice_pool`
по `video_id`. Голос коммитится ботом («голос и заявка на клипы после фазы 1»),
агент скачивает `assets/voice/<id>/voice_final.wav` и отдаёт заказчику слушать.

## Нельзя

- Перегенерировать голос на перерендере визуала (`from_step` P7/P11).
- Менять `text` блоков после голоса — это новый `video_id`.
- Ускорять выше 1.35 — съедаются окончания слов.
