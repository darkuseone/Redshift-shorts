# Как писать сценарий REDSHIFT

Основа — `script_playbook.md` (петля удержания: удар → вопрос → затяжка →
ответ → CTA). Здесь — **голос канала**, каким его хочет заказчик. Перед каждым
сценарием перечитай `config/owner_style.md`: там его правки, они сильнее этого файла.

## 1. Язык: объясняй как другу

- Сложное — через бытовое: «тебя вытянет, как макаронину», «время для тебя
  застынет, как видео на паузе». Одно сравнение на мысль.
- Термин можно, если он «умный» и цепляет («спагеттификация») — но один-два
  на ролик и сразу простыми словами.
- Короткие фразы: 4–10 слов. Одна мысль — одно предложение.
- На «ты». Зритель — участник: «ты падаешь», «твой кот».
- Разговорные слова разрешены: «вообще», «прикинь», «ну такое». Канцелярит —
  нет: «является», «осуществляет», «данный».
- Цифры — конкретные и проверенные, но не ради цифр. В поп-науке денег может
  не быть — предупреждение `FACT_MONEY_MISSING` здесь нормально.

## 2. Хук (0–3 с)

Хук — одна фраза ≤3 с речи (P0: `HOOK_TOO_LONG`). **Не повторять тип два
ролика подряд.** Ротация:

| Тип | `meta.hook.style` | Пример |
|---|---|---|
| Провокационный вопрос | `question_flash` | «Что будет с твоим котом в чёрной дыре?» |
| Дерзкое утверждение | `bold_claim` | «Твой кот переживёт падение в чёрную дыру. Почти.» |
| Цифра-удар | `number_slam` | «Сто километров. Такой длины станет твой кот.» |
| Холодное открытие | `cold_open` | 1 с кадра без слов → «Это не мультик.» |
| Прямо в лицо (с аватаром) | `avatar_direct` | «Стоп. Не листай. Это про тебя.» |

Провокация — через неожиданного героя (кот, девушка, жираф, твой телефон) или
через «ты». Запрещено: «привет», «сегодня разберём», «с вами».

## 3. Живая подача

- **Сарказм и ирония** 1–3 раза за ролик: «Горизонт событий вообще не больно.
  Пока.» / «Учёные называют это спагеттификацией. Звучит вкусно. Не вкусно.»
- **Смена темпа:** быстрые короткие фразы → одна длинная → удар.
- **Драматическая пауза:** после саркастической реплики — `silence_after_ms`
  (800–2000) в блоке. В этом окне картинка работает за голос: взгляд аватара
  в камеру с каменным лицом, стоп-кадр, тишина с одним SFX.
- **Аудиотеги** для голоса — в `tts_text` блока, не в `text`
  (`docs/director/VOICE.md`).

## 4. Финал — одно из двух

1. **Петля:** последняя фраза подводит к первой, чтобы повтор ролика звучал как
   продолжение. «…и поэтому никто не знает, что будет с твоим котом» → начало
   «Что будет с твоим котом в чёрной дыре?». `cta.type: "visual_loop_seam"`
   или `"open_question"`.
2. **Подпишись/лайк:** коротко и с юмором — «Подпишись, пока тебя не
   затянуло». `cta.type: "subscribe_like"`.

Не оба сразу. Чередуй между роликами.

## 5. Структура на 30 с (пример)

| Блок | Роль | Сек | Что происходит |
|---|---|---|---|
| b1 | hook | 0–3 | провокация |
| b2 | setup | 3–9 | «сначала ничего не будет» — неожиданность |
| b3 | develop | 9–16 | ставка растёт, сарказм + пауза |
| b4 | twist (`answers_hook`) | 16–24 | ответ, которого не ждали, картинка-удар |
| b5 | cta | 24–30 | осадок + петля или «подпишись» |

Ответ на хук — на 40–88 % хронометража (P0 `PAYOFF_TOO_EARLY/LATE`).
Для 30 с при темпе 1.25 нужно ~200–230 слогов речи.

## 6. Ударения

Русский TTS путает ударения. В сомнительных словах — знак ударения в `tts_text`
(`сентября́`) или правило в `config/pronunciation.json`. Всегда проверяй:
имена, термины, числительные в косвенных падежах, омографы (зáмок/замóк).

## 7. Как показать сценарий заказчику

```
Хук (bold_claim): «…»
b1 hook   | текст | картинка: …
b2 setup  | текст | картинка: …
…
Финал: петля / подпишись
Источники: 1) … 2) …
Хронометраж ~NN с
```
После одобрения — `scripts/<video_id>.json` с тем же текстом дословно.
