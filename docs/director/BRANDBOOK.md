# Брендбук REDSHIFT: как ролик узнают до первого слова

Источник правды — `config/brandbook.json` (секции `colors`, `brand_roles`,
`signature`). Этот файл объясняет, как им пользоваться режиссёру.

## Палитра: четыре цвета и ничего больше

| Цвет | HEX | Токены | Значит | Что им красим |
|---|---|---|---|---|
| **Чёрный** | `#0A0A0B` / `#111214` / стекло `#141517` | `space_deep`, `ink`, `panel` | основа, космос, тишина | фон карточек, плашек, полноэкранного текста, финала |
| **Белый** | `#FFFFFF` | `bg_pure` | голос канала | весь текст |
| **Красный** | `#D7263D` (soft `#F2566B`, deep `#8E1627`) | `accent*` | **что почувствовать**: эмоция, опасность, удар | одно ключевое слово, «?» хука, заливка субтитров, Subscribe, красная точка REDSHIFT |
| **Бирюзовый** | `#36EFFF` (soft `#7AF0FF`, deep `#0BB8C9`) | `cyan*` | **что узнать**: цифры, данные, технологии | счётчики и графики, рамки плашек, источник, технические уголки, сканы |

Правила:
1. В одном элементе — один акцент. В кадре доминирует один, второй — деталь.
2. Красным — одно слово, не строка. Бирюзой — цифра или знак данных.
3. Бирюзовый текст — только на тёмном; на белом — `cyan_deep`.
4. Акцент ≤12 % кадра (QC-30). Футаж своего цвета не перекрашиваем.
5. Смысл блока → цвет: `emphasis_family` `myth`/`emotion` → красный,
   `tech`/`number`/`source` → бирюза.
6. В коде цвет — только токеном. Новый hex-литерал в рендере — брак.

## Шрифты

| Роль | Гарнитура | Где |
|---|---|---|
| display | Oswald Bold, капс | хук, полноэкранный текст, цифры, REDSHIFT |
| subtitle | Montserrat Black, капс | субтитры, плашки |
| mono | JetBrains Mono Bold | подписи источника, тикеры, код |

## Пять фирменных элементов (в каждом ролике)

1. **Субтитры.** Белые, одна строка, текущее слово заливается красным,
   красное гало. Один жест `gradient-fill` во всех роликах, космос тоже
   (`subtitles.one_style_all_videos`).
2. **Карточка хука.** Чёрный фон, белый Oswald, одно слово/знак красным
   («КОТ В ЧЁРНОЙ **ДЫРЕ?**»), бирюзовые уголки. Шаблоны
   `intro-hooks/hook-question-flash`, `hook-blackout-word`, `hook-number-slam`.
3. **Технические уголки.** Бирюзовые скобки и засечки по рабочей зоне на
   карточных моментах, ≤3 раз за ролик (`brand_marks`).
4. **Плашки — чёрное стекло.** Панель 48 %, белый текст, рамка 2 px бирюзой
   (факт, источник) — `lower-thirds/source-domain`, `dark-card`.
5. **Финал.** REDSHIFT белым на чёрном + красная точка + красная кнопка
   Subscribe (`outro-cta/logo-brand-close`).

Плюс фирменный переход на смысловом переломе (хук → развитие, ответ):
`transitions/chromatic-radial-split` — расслоение красный/бирюза.

## Как брендбук ложится на таймлайн режиссёра

| Момент | Приём | Цвет |
|---|---|---|
| 0–1.5 с хук | `intro-hooks/hook-question-flash` на футаже героя | белый + красный «?» |
| перелом хук → развитие | `transitions/chromatic-radial-split` | красный/бирюза |
| цифра в речи | `data-viz/counter-roll`, `stat-countup-card` | бирюза |
| источник | `lower-thirds/source-domain` | чёрное стекло + бирюза |
| эмоция/удар | `text-fullscreen/kinetic-stack`, `number-slam-card` с `accent_word` | белый + одно красное слово |
| финал | авто-CTA REDSHIFT | белый + красный |

Не ставить на футаж без ведущего `hero-devices/*`: многие кладут сплошную
плиту и прячут кадр. Слово поверх кадра — `fullscreen` с `footage`.

## Герои-стикеры

Героя ролика рисуем, а не снимаем: нарисованная иллюстрация из бесплатного
стока, белая обводка-наклейка, движение рывками как гифка поверх настоящих
кадров NASA (`tools/sticker_anim.py`, `FOOTAGE.md` §3a).

## Нельзя (уже ловили)

- Красный текст светлым `accent_soft` — читается розовым. Текст и сплошные
  плашки — только `#D7263D`.
- Межстрочный 0.94 у заголовков — съедает точки Ё и дужку Й. Минимум 1.06.
- Сплошная плита hero-приёма на футаже без ведущего.

Наглядная версия брендбука (цвета, шрифты, кадры) — страница-артефакт
«Брендбук REDSHIFT» у заказчика.

## Проверка

Пробный рендер 22.09 (кот + NASA PIA25440/PIA16695) — кадры в PR. Субтитры
читаются на светлом коте и на тёмном космосе. Одно место требует
внимания: красная заливка субтитра поверх красного диска — там режиссёр
либо сдвигает окно, либо берёт кадр потемнее.
