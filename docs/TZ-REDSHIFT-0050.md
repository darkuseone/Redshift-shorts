REDSHIFT. Умное простым языком.

- Короткие предложения. Одна мысль — одна фраза.
- Сначала факт и цифра, потом термин.
- Сарказм уместный («самолёт не извиняется»), не стёб ради стёба.
- Не лектор. Не жаргон с первой секунды (не начинать с «уравнения Навье-Стокса»).
- Wordmark на экране всегда `REDSHIFT` латиницей, без точки, без «РЕДШИФТ.».

## 8. Правила кадра (удержание)

Железные:

1. Шот **2–7 с**. Потолок одного куска на экране — **10 с**. 10 с один фон + только сабы = брак.
2. В каждом куске что-то происходит: движение футажа, переход, смена цифры, появление карточки, Ken Burns только как добавка к живому клипу. Не статика.
3. Соседние шоты — разный визуал.
4. Футаж = смысл реплики. Метафора «касса» не выбирает сток «касса» и не выбирает HTML-туториал.
5. Один пункт жизни — один кадр: погода отдельно, крыло отдельно, трубы отдельно, кровь отдельно. Не одна карточка со всеми словами.
6. Больше цифр на экране, меньше пустой текстуры.

Карта смыслов:

| речь | кадр | не кадр |
|---|---|---|
| миллион / приз | одна сильная карточка `$1 000 000` | два дубля подряд, статья OpenAI |
| вода / Навье-Стокс | вода, течение | бетон, стена |
| Astra / GPT-6 | статья openai.com, кластер, модель | абстрактный график «ради графики» |
| 88 ч / 10 000 / 2.7M | тёмная карточка на живом фоне | белая плашка, разрезанное число |
| Lean | код доказательства / проверка шагов | HTML «Hello JS», касса, руки на ноуте без кода доказательства |
| Clay | институт / документы | плотина, глина, бетон |
| дыра в стене | метафора без трещины (свет в щели двери, обрыв графика, штамп REJECT) | cracked wall |
| CTA | `REDSHIFT` ровно | косой текст, точка после имени |

## 9. ГиперFrames / сабы / карточки

Сабы по умолчанию: компонент `caption-gradient-fill`  
(`npx hyperframes add caption-gradient-fill` → `compositions/components/caption-gradient-fill.html`).

- Акцент слова — **красный**, не коралл и не оранж.
- Не рвать слово посередине (`ПРОВЕРЯЕТЧЕК` запрещён).
- Не ставить предлог «А» отдельной карточкой.
- Цифры в сабах как на карточке: `88`, не «восемьдесят восемь» и не «80 8».

Информационные карточки: клон логики IMG_6483.

- тёмный полупрозрачный фон
- скругление
- тонкая рамка красная
- акцент красный
- текст помещается целиком, без обрезки `2 700 000`
- не белая плашка на живом футаже
- не пустое «окно» внутри карточки
- не косой/скошенный шаблон — выключить в манифесте/выборщике, чтобы пайплайн его больше не брал

Source-card openai.com:

- почти нижний угол
- без красного

HTML-композиция, если пишется руками: таймлайн с явными `data-start` / `data-duration`, слои не пересекаются по смыслу, 1080×1920 или 1920×1080 с последующим кропом пайплайна — как уже принято в репо. Не выдумывать новый рендерер.

## 14. QC и релиз

Рубрика: `config/qc_agent_rubric.json`. Релиз только если **все оси ≥9 и среднее ≥9**. Оси пустые (`score: null`) = не релиз.

Перед заявкой в Actions и после артефакта агент сам:

1. Проходит анти-чеклист §7.
2. Проверяет хук 0–3 с: движение, ставка, нет большого русского слова.
3. Проверяет, что нет шота ≥10 с без смены картинки.
4. Считает долю аватара 20–40 %.
5. Проверяет сабы и карточки: числа целые, бренды латиницей, `REDSHIFT` без точки.
6. Заполняет scorecard числами и заметками. Ось <9 — чинит ось, не рисует девятки.
7. Пишет в PR таблицу: `t | речь | кадр | asset_id | длительность шота`.
8. Прикладывает cost_report. ElevenLabs/HeyGen в 0050 будут ненулевые — это ожидаемо. Лишний Grok по сырому стоку — нет.

Неблокирующий QC-28 (пауза в хуке) 0049 на 0050 не повторять: хук плотный.
