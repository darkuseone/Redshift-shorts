Как открыть ТЗ в Claude Code
----------------------------
Маркус, самый короткий путь — запустить Claude Code в корне репозитория и
попросить его прочитать файл. Тогда у агента сразу будет и документ, и код,
на который документ ссылается номерами строк:

    cd /workspace/repos/Redshift-shorts
    claude
    > прочитай /workspace/tz/REDSHIFT-IMPROVE-TZ-vNEXT.md, начни с раздела 2
      (executive summary), потом покажи таблицу DoD из раздела 4.3

Чтобы сразу отдать документ в работу исполнителю:

    > прочитай /workspace/tz/REDSHIFT-IMPROVE-TZ-vNEXT.md и исполни фазу Q1,
      шаг за шагом, с тестами после каждого шага. Код не пушить без
      зелёного pytest.

Без агента, просто прочитать:

    less /workspace/tz/REDSHIFT-IMPROVE-TZ-vNEXT.md
    # или в редакторе / просмотрщике Markdown

Три файла этого прогона
-----------------------
/workspace/tz/REDSHIFT-IMPROVE-TZ-vNEXT.md   — само ТЗ (волна качества Q1/Q2/Q3)
/workspace/tz/OPUS-IMPROVE-STATUS.md         — статус, координаты, метрики успеха
/workspace/tz/OPUS-IMPROVE-SESSION.txt       — этот файл
