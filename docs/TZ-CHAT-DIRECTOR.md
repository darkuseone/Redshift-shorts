# ТЗ: чат-режиссёр REDSHIFT

**Дата:** 2026-09-22 · **Статус:** в работе · **Основание:** голосовое ТЗ заказчика от 22.09

## 0. Что меняется одной фразой

Раньше ролик «придумывал» GitHub: эвристика P7/P8 выбирала футаж по ключевым
словам, эвристика P11 — один-два шаблона из 173. В GitHub нет нейросети, поэтому
выбор получался случайным и плоским.

Теперь **режиссёр — нейросеть в чате** (Claude Code, Grok/GrokBot, Gemini,
любая другая). Она пишет сценарий, ищет и смотрит своим зрением реальный
материал, выбирает шаблоны и VFX по смыслу, готовит голос и отдаёт GitHub
**готовый режиссёрский таймлайн**. GitHub Actions — станок: скачивает то, что
указано, ставит в указанное окно, рендерит, меряет звук, отдаёт mp4.

## 1. Разбор текущего состояния (ветка `pipe/0051`, PR #28, и `main`)

| Симптом | Причина в коде |
|---|---|
| В ролике 1–2 шаблона | У блока один `overlay` с одним `template_hint`; P11 выбирает остальное эвристикой `TemplatePicker.pick(... exclude=used_templates + ban_templates)`, режет капами (`fullscreen_text_per_video [2,4]`, `cut_share_min 0.70`, `dynamic_transition_min_gap_sec 6.0`) и банами, которые копились в 0051 r10…r20 (`ban hero-devices`, `ban red plates`…) |
| Мало VFX/переходов | `cut_share_min: 0.70` — ≥70 % склеек обязаны быть прямыми; переходы не чаще раза в 6 с |
| Футаж «не про то» | Отбор по английским запросам из `broll_queries` + pHash + Grok vision (выключен: `vision.skip_live=true`) — фактически по тегам |
| 20 ревизий на ролик | Каждая правка визуала = ещё один бан/хак в `assemble.py` (0051: +239 строк) вместо решения режиссёра |
| Сценарий плоский | `script_playbook.md` про структуру петли, но не про язык: нет правила «простыми словами», сарказма, пауз, ротации хуков |
| Голос плоский | `stability 0.30`, одна подача; нет аудиотегов v3 (`[laughs]`, `[sarcastic]`), нет драматической паузы — P3 режет все паузы до 55–85 мс |
| Инструкции только под Cursor | `CLAUDE.md`, `instruction.md §0` написаны для Cursor; у Grok/Gemini нет своей точки входа |

Ветка `pipe/0051` — итерации одного ролика (баны под конкретные кадры). В основу
новой системы она **не** берётся: работа идёт от `main`, PR #28 остаётся как есть.

## 2. Новый порядок работы (один для любой нейросети)

```
0. Тема от заказчика
1. Ресёрч: реальные источники, свежие новости (веб, X, соцсети, NASA, arXiv…)
2. Сценарий (правила — docs/director/SCRIPT_STYLE.md)
3. СТОП → сценарий заказчику. Правки → учесть → запомнить стиль (config/owner_style.md)
4. После одобрения:
   4a. Голос: ElevenLabs, NIKITA2, eleven_v3, темп 1.2–1.3, аудиотеги, паузы
   4b. Футаж: субагент/поиск по вебу → скачать → посмотреть своим зрением → отобрать
   4c. Генерация ≤20 %: сначала проверить xAI; нет — Magnific (MCP/браузер); нет — только реальный материал
   4d. Шаблоны и VFX: из каталога docs/director/TEMPLATES.md, по смыслу, много
   4e. Таймлайн: director-секция в scripts/<id>.json
5. tools/director_check.py → ноль ошибок
6. Push + заявка config/ci_build_request.json → Actions рендерит
7. QC по qc_pack (кадры + звук), правки только с кэша
```

Пункт 3 обязателен, пока заказчик не скажет «дальше без согласования».

## 3. Сценарий

1. **Простой язык.** Сложное — через бытовое сравнение («тебя вытянет, как
   макаронину»). Термин допустим один-два на ролик и сразу объясняется.
2. **Хук в первые 3 с**, ротация типов (не два ролика подряд одинаково):
   вопрос-провокация («Что будет с твоим котом в чёрной дыре?»), дерзкое
   утверждение, цифра-удар, холодное открытие кадром, «ты» в кадре.
3. **Живая подача:** сарказм и ирония 1–3 раза за ролик, короткие фразы,
   разговорные слова, обращение на «ты».
4. **Драматическая пауза:** после саркастической реплики — `silence_after_ms`
   (до 2500) в блоке; в это окно режиссёр ставит «взгляд в камеру» аватара или
   стоп-кадр/тишину.
5. **Финал:** либо петля (последняя фраза подводит к первой — ролик крутится
   по кругу), либо «подпишись/лайк» (`cta.type = subscribe_like`). Не оба.
6. **Факты только из источников** (`sources[]`), цифры проверены. Выдуманные
   цифры — брак.
7. **Ударения:** в сомнительных словах — `+` или словарь `config/pronunciation.json`.
8. **Длительность:** короткий формат 25–35 с разрешён (`limits.duration_sec: [25, 70]`).
9. **Память стиля:** каждая правка заказчика в сценарий — запись в
   `config/owner_style.md` (что было → что стало → правило).

## 5. Футаж

- **Реальный материал ≥80 %.** Источники по приоритету: NASA/ESA/NOIRLab
  (PD/CC), Wikimedia Commons, Internet Archive, Magnific stock (подписка,
  100 скачиваний/день), Pexels/Pixabay, пресс-материалы компании (логотипы,
  скриншоты) с подписью источника.
- **Генерация ≤20 %** хронометража. Порядок: xAI (проверить ключ заранее
  пробным запросом в Actions/чате; 4xx/нет баланса → пропуск) → Magnific
  (MCP `images_generate`/`video_generate` или браузер GrokBot, бесплатные
  модели) → нет генерации, только реальный материал.
- **Режиссёр смотрит сам.** Скачать кандидата, вытащить 3–5 кадров
  (`ffmpeg`), посмотреть своим зрением. Vision xAI/Gemini на отбор не тратить.
- Каждый футаж в таймлайне — с `source`, `license`, `page_url`; URL или файл
  в репо (`assets/footage/director/<id>/`, ≤15 МБ на файл).
- Субагент поиска (Claude Code: `Agent`; GrokBot/Gemini: свой браузер) ищет
  по каждому окну 2–4 кандидата, возвращает прямые ссылки + лицензию.

## 6. Шаблоны и VFX

- Режиссёр выбирает шаблоны **явно** по окнам сценария из
  `docs/director/TEMPLATES.md` (генерируется из `templates/manifest.json` и
  реестров рендереров: id → renderer → params).
- Норма динамики: смена картинки/событие каждые 1.5–2.5 с; ≥6 разных
  приёмов на 30 с; переходы-VFX (whip, zoom-through, glitch, light leak,
  gravitational lens…) там, где смысловой перелом, а не на каждом стыке.
- В director-режиме эвристика P11 не перебивает решения режиссёра: её баны,
  капы и ротация не применяются к окнам таймлайна; творческие QC-гейты
  (доля склеек, число полноэкранных, частота переходов) — предупреждения.

## 7. Режиссёрский таймлайн (контракт с GitHub)

Секция `director` в `scripts/<id>.json` (полная схема — `docs/director/TIMELINE.md`):

```json
"director": {
  "footage": {
    "bh_disk": {"src": "https://images-assets.nasa.gov/.../orig.mp4",
                "source": "nasa", "license": "public_domain",
                "page_url": "https://images.nasa.gov/details/...", "in_sec": 2.0}
  },
  "shots": [
    {"block": "b1", "footage": "cat_stare", "motion": "kenburns",
     "transition": "zoom_punch"},
    {"block": "b1", "at": "чёрной", "footage": "bh_disk",
     "transition": "gravitational_lens"},
    {"block": "b2", "fullscreen": {"template": "text-fullscreen/number-slam",
                                   "content": "100 КМ"}}
  ],
  "overlays": [
    {"template": "data-viz/counter-roll", "block": "b3", "at": "сто",
     "dur": 1.6, "params": {"value": 100, "suffix": " км"}}
  ]
}
```

- `at` — слово блока, с которого начинается окно (якорь к речи, а не к
  секундам: паузы режутся после). Без `at` — начало блока.
- Шот длится до следующего шота. `hero` — приём поверх кадра.
- Аватар: `{"block": "b2", "avatar": true}` — окно отдаётся ведущему.

## 8. Режим без аватара

`meta.avatar_mode: "none"` — P1 не требует первого появления до 0:06 и доли
20–40 %, P5 не создаёт окон ведущего, P6 не вызывается, QC-2/11/18 не
блокируют. Для пробных роликов и роликов без ведущего.

## 9. Инструкции для любой нейросети

- `AGENTS.md` — канон протокола (читают Codex, Gemini CLI, Grok, Cursor…).
- `CLAUDE.md`, `GEMINI.md`, `GROK.md` — точки входа, ведут в `AGENTS.md`.
- `docs/director/` — `SCRIPT_STYLE.md`, `FOOTAGE.md`, `VOICE.md`,
  `TIMELINE.md`, `TEMPLATES.md`.
- GrokBot-особенность: может логиниться в Magnific в браузере и генерировать
  бесплатными моделями — описано в `FOOTAGE.md`.
