# Отклонённые приёмы

Журнал того, что пробовали и **не** берём. Ведётся, чтобы не возвращаться к
решениям, которые уже разбирались (§7.8).

## Из ДНК референсов (§2.2)

| Приём | Почему отклонён |
|---|---|
| Спикер как постоянный якорь кадра | Аватар 35–60 %; якорь — текст и футаж. Постоянный говорящий в кадре тратит кредиты и убивает разнообразие |
| Микрофон, подкаст-атрибутика | Неприменимо к формату |
| Жёлтый акцент, тёмные фоны | Противоречит утверждённому брендбуку (§3.3, конфликт K-1 закрыт в пользу светлой бело-красной схемы) |
| Кликбейт, «ШОК», капс в озвучке | Тон канала — тихий восторг и ясность (§2.3) |

## Технические решения

| Решение | Почему отклонено |
|---|---|
| Кроссфейд между планами | Запрещён §4.3, кроме ухода в белое на финальном кадре |
| Растяжение кадра под 9:16 | Запрещено §3.6.6 — только crop или letterbox |
| Blurred pillarbox по умолчанию | §3.6.5 разрешает не чаще 2 раз за ролик; применяется только к сверхширокому кадру (≥2.1:1), где кроп теряет 75 % ширины |
| Кроп всегда по центру кадра | Центр часто пустой, субъект стоит в трети. Кроп идёт по детектированному центру плотности деталей |
| Ken Burns через `zoompan` в ffmpeg | Поведение фильтра плохо предсказуемо на видеовходе; движение считается покадрово в композиторе, где им можно управлять точно |
| Хранение музыкальных подложек в WAV | 5 файлов по 60 сек — 67 МБ в git. На уровне −32 LUFS под речью разница с AAC 96k неразличима |
| Мемы из мем-агрегаторов | §14.3 и §10.4: фрагменты фильмов и ТВ с оригинальным аудио — прямой риск Content ID |
| Генерация SFX при заполненной библиотеке | §4.4.4: повторная генерация уже имеющегося звука — ошибка процесса, а не «дополнение» |
| Синтез SFX в библиотеку | Заказчик заменяет синтетические короткие звуки своими записями. Как с музыкой: `fill-libraries` не имеет права их воссоздать |
| Оценка футажа vision-моделью до дешёвой отбраковки | Шаг 1 §7.3 отсеивает 50–60 % бесплатно; платить за них зрением незачем |
| Генерация всего ролика аватаром | §7.4.1: посегментная генерация экономит больше половины кредитов |
| Локальное матирование через rembg по умолчанию | R-2: onnxruntime на CPU-раннере не замерен. Функция остаётся за флагом до замера на целевом окружении |

## Формулировки правил, которые оказались неверными

| Было | Стало | Причина |
|---|---|---|
| «Два аватар-сегмента подряд запрещены» — по слотам | По разным генерациям и по двум полнокадровым сегментам одного блока | Внутри блока аватар — одно непрерывное видео; соседние сплиты стыка не создают |
| Покрытие субтитров считалось долей **секунд** | Долей **слов** | Между словами есть паузы: доля секунд никогда не даст 100 %, и проверка была бы всегда красной |
| Уровень подложки измерялся до ducking и до нормализации микса | В готовом миксе | Расхождение с фактом достигало 6.8 дБ |
