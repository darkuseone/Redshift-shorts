# Библиотека отобранного материала

Индекс лежит в `cache/footage_index.json`. **Сами файлы в git не живут:**
S3 (`REDSHIFT_S3_*`), если секреты есть, иначе артефакт Actions. Локальный
каталог — кэш раннера / машины сборки.

Сюда попадает настоящий материал, который прошёл отбор: сток, кадр со страницы
издания, архивная запись. Каждый файл уже проверен зрением, приведён к
вертикали и сведён к палитре канала.

Чего здесь нет и не будет:

* сгенерированного — он AI и не должен накапливаться преимуществом;
* синтетики мок-прогонов.

Потолок локального кэша — `storage.max_bytes`. Дальше LRU
(`python -m src.cli maintenance`).
