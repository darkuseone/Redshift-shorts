# Библиотека отобранного материала

Сюда попадает **настоящий** материал, который прошёл отбор: сток, кадр со
страницы издания, архивная запись. Каждый файл уже проверен зрением (§7.3),
приведён к вертикали и сведён к палитре канала — переиспользовать его можно
как есть.

Чего здесь нет и не будет:

* **сгенерированного** — он AI, он дёшев в повторе и он не должен накапливаться
  преимуществом над настоящим кадром;
* **синтетики мок-прогонов** — она не существует ни на одном диске, а в общей
  базе занимала 92 % записей и уводила живые ролики в генерацию.

Индекс лежит в `cache/footage_index.json`, файлы — здесь. Пара нераздельна:
запись без файла — это слот, ушедший в генерацию.

Потолок — `storage.max_bytes` (400 МиБ), дальше LRU вытесняет самое давно не
использованное (`python -m src.cli maintenance`). Потолок здесь не про диск, а
про историю git: удалённый файл остаётся в ней навсегда.
