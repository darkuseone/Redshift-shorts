# REDSHIFT

Система автоматической сборки YouTube Shorts. Принимает JSON-сценарий и без
участия человека выдаёт готовый вертикальный ролик 1080×1920 длительностью
35–70 секунд — **в двух версиях монтажа** из одного набора материалов.

Реализация по ТЗ v2.0. Правила сборки живут в [`instruction.md`](instruction.md)
как исполняемый документ, а не в переписке.

---

## Быстрый старт

```bash
pip install -r requirements.txt

# Проверить сценарий, ничего не потратив
python -m src.cli validate --script scripts/redshift_0042.json

# Собрать ролик. Без ключей всё работает в mock-режиме
python -m src.cli --set providers.mode=mock run --script scripts/redshift_0042.json

# Результат
ls output/redshift_0042/
```

Нужен `ffmpeg`. Если системного нет — подойдёт статическая сборка из
`imageio-ffmpeg`, она уже в зависимостях.

## Режимы работы

Все внешние сервисы (ElevenLabs, HeyGen, Gemini, Grok, Magnific, Pexels, NASA…)
имеют пару реализаций и переключаются одним ключом:

| Режим | Поведение |
|---|---|
| `live` | только реальные API; нет ключа → ошибка |
| `mock` | ни одного внешнего вызова, полностью детерминированно |
| `auto` | live там, где есть ключ; остальное — mock с предупреждением |

```bash
python -m src.cli --set providers.mode=live run --script scripts/x.json
```

Mock — не заглушка ради зелёного CI: он синтезирует настоящие медиафайлы.
Речеподобная дорожка со слоговой структурой, паузами и вдохами (на ней работают
срез пауз и выравнивание), видеоклипы разной ориентации (на них работают кроп
9:16, pHash и Ken Burns), говорящий аватар с движением рта по огибающей речи
(на нём проверяются липсинк и кадрирование).

## Пайплайн

```
P0  Валидация сценария        P7  Поиск B-roll
P1  Планирование кадра        P8  Трёхступенчатая оценка
P2  TTS с запасом длины       P9  Генерация пустых слотов
P3  Оптимизация речи          P10 SFX, подложка, микс
P4  Выравнивание по словам    P11 Сборка edit-планов A и B
P5  Монтажный план            P12 Рендер, QC, артефакты
P6  Аватар посегментно
```

Каждый шаг идемпотентен и кэшируется по хешу входа. Падение на шаге N не требует
перезапуска с начала:

```bash
python -m src.cli run --script scripts/x.json --from P7      # продолжить
python -m src.cli run --script scripts/x.json --only P11 P12 --force
python -m src.cli steps                                       # контракты шагов
```

## Команды

```bash
python -m src.cli validate --script scripts/x.json   # P0, коды ошибок §8.2
python -m src.cli fonts-check                        # кириллица и лицензии гарнитур
python -m src.cli libraries                          # состояние библиотек и лимитов
python -m src.cli fill-libraries --kind sfx          # долив до лимита
python -m src.cli templates --category transitions   # каталог шаблонов
python -m src.cli maintenance --dry-run              # что вытеснит LRU
python -m src.cli learn --video-id x --choice A      # записать выбор версии
```

## Структура

```
config/       конфиг, брендбук, словарь ударений, источники, предпочтения монтажа
src/          пайплайн P0…P12, общие подсистемы, провайдеры, слой рендера
templates/    135 шаблонов в 12 категориях
assets/       SFX (20), музыка (5), мемы (≤100), шрифты — капнутые библиотеки
cache/        индекс кэша футажей; сами файлы во внешнем storage
scripts/      входные JSON-сценарии
.claude/      16 скиллов: исполняемая форма правил сборки
tools/        генератор каталога шаблонов, проверка артефактов прогона
```

## Что сделано своими средствами и почему

| Подсистема | Почему не библиотека |
|---|---|
| Громкость по ITU-R BS.1770-4 | нужна была и покадровая проверка, и независимая сверка с ebur128 из ffmpeg (расхождение 0.08 LU) |
| pHash / dHash | 60 строк против зависимости; устойчив к ресемплингу, JPEG и экспозиции |
| Парсер шрифтов (cmap, name, OS/2) | fontTools ради трёх таблиц — лишний вес на раннере |
| Синтез SFX и подложек | нулевой риск Content ID и полная лицензионная чистота звука канала |
| Композитор кадров | полный контроль над Ken Burns, переходами и графикой; поток в один кадр в памяти |

Внешних зависимостей пять: numpy, Pillow, PyYAML, requests, jsonschema.

## Тесты

```bash
python -m pytest tests/ -q
```

Проверяются в том числе правила ТЗ, которые легко нарушить незаметно: доля
аватара и число появлений, интервал между визуальными событиями, длина плана,
уровень подложки в готовом миксе, покрытие субтитров, отсев на первом шаге
оценки, лимиты библиотек, safe zones и доля акцентного цвета в кадре.

## Ключи

Ни один ключ не хранится в конфиге — только имена переменных окружения.
Редактирование секретов встроено в форматтер логов, поэтому значение ключа не
попадёт в лог или артефакт, куда бы оно ни просочилось.

```
ELEVENLABS_API_KEY  ELEVENLABS_VOICE_ID  HEYGEN_API_KEY
GEMINI_API_KEY      XAI_API_KEY          MAGNIFIC_API_KEY
PEXELS_API_KEY      PIXABAY_API_KEY      NASA_API_KEY
REDSHIFT_S3_*                            # внешнее хранилище кэша футажей
```
